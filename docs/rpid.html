What changed

Every Aqua job needs a project ID.

An RPID (research project ID) tells QUT which research project a job belongs to. Aqua checks it when you submit.

Required in every submission from 2 November 2026.

That includes job arrays, interactive jobs and retries. Start using it now rather than relying on the grace period.

Step 1

Find your RPID.

  1. Look it up

    Sign in to the QUT Data Management Plan system and open your research project. An RPID is six uppercase letters followed by four digits. Menu labels may differ slightly from this description.

  2. Can’t find it? Ask

    Your project lead or QUT eResearch can confirm the right ID and that you may use it. Never borrow another project’s ID or use an example ID such as ABCDEF1234.

A correctly formatted ID is not proof that you are authorised; the scheduler checks that.

Step 2

Add it to your job scripts.

Choose one of these two ways.

  1. Write it into the script

    Put a literal ID in the #PBS lines at the top, before any commands:

    Inside job.pbs · replace the example ID 
    #PBS -P ABCDEF1234

  2. Or pass it when you submit

    Useful when one script is shared across projects:

    On Aqua · replace YOUR_REAL_RPID 
    export AQUA_RPID=YOUR_REAL_RPID
qsub -P "$AQUA_RPID" job.pbs
Don’t write #PBS -P $AQUA_RPID.

PBS reads #PBS lines before the shell runs, so shell variables are not expanded there.

Add -P "$AQUA_RPID" to array, interactive and retry wrappers too. Keep your real ID out of files you share publicly.
